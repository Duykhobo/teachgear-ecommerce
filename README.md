# 🛒 TechGear E-Commerce System

TechGear E-Commerce là hệ thống bán hàng công nghệ trực tuyến với kiến trúc Microservices / Decoupled Backend & Frontend.

## 📁 Cấu Trúc Thư Mục Project

- `server/`: Server Backend API (Node.js, Express, TypeScript, MongoDB Atlas, Redis, SePay VietQR, Telegram Bot).
- `client/`: Single Page Application Frontend (React / Next.js).

---

## ⚡ Bắt Đầu Nhanh (Quick Start)

### Backend Server (`server/`)
```bash
cd server
npm install --legacy-peer-deps
npm run dev
```

### Chạy Kiểm Thử (Tests)
```bash
cd server
npm run test
```
